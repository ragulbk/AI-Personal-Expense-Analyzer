\# AI-Powered Personal Expense Analyzer



\## About the Project



AI-Powered Personal Expense Analyzer is a Java-based application

that helps users manage expenses, monitor budgets, understand

spending patterns, and receive AI-powered financial insights.



The application integrates Google's Gemini AI to analyze expense

records and provide personalized suggestions for better money

management.



\## Features



\### Expense Management

\- Add and manage daily expenses.

\- Categorize expenses.

\- Store expense records locally.

\- Validate user inputs.



\### Expense Analysis

\- Calculate total spending.

\- View monthly spending reports.

\- Compare spending between two months.

\- Search expenses.

\- Export expense records to CSV.



\### Budget Management

\- Set monthly budgets.

\- Set category-wise budget limits.

\- Receive budget-related alerts.

\- Get monthly budget recommendations.



\### AI-Powered Features

\- Analyze personal expense records using Gemini AI.

\- Identify spending patterns.

\- Find high-spending categories.

\- Receive personalized money-saving suggestions.

\- Ask questions through an interactive AI assistant.



\## Technologies Used



\- Java

\- Google Gemini API

\- Java HTTP Client

\- Git

\- GitHub

\- CSV and File Handling
